# v0.7.0 紧凑胶囊与完整周期详情

## 当前需求与实现

- 收起 128×34px、约 3.76:1，单行展示余额整数及两个服务的最高周期用量。精确余额在展开和悬停中保留。
- 展开 168px 宽，三服务纵向排列，当前数据约 382px 高；恢复周期进度和重置信息，字体为 10–13px，锁按钮点击区域 24px。
- 默认 5 秒自动刷新；展开态右上角显示手动刷新按钮，点击时保持展开状态，页面隐藏时暂停自动刷新。
- CommandCode 五小时/周来自官方 windowLimits；月比例来自 billing-period 下 totalMonthlyCredits / (totalMonthlyCredits + credits.monthlyCredits)。充值/赠送不混入月比例，缺失显示未知。月重置时间尚无接口字段。
- 独立初始位置随异步侧栏更新，自动避开底部入口；有无鲸息均可使用。手动位置优先，锁定及位置持久化保留。
